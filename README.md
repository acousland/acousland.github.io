# Aaron Cousland’s apps

Public app portfolio at **https://acousland.github.io/**.

A static HTML page hosted by GitHub Pages from the root of the `main` branch. No dependencies or build step.

## Update the page

Edit `index.html` and push to `main`. GitHub Pages publishes the update automatically. Screenshot assets live in `assets/`.

The collection contains Mondrian, Screener, co-written, Marginal, and Agora. Mondrian links to its public release repository; its source remains private. Screener links to the releases list because its current builds are prereleases. Agora is listed as coming soon until a public destination is available.

Mondrian, co-written, and Marginal use demo screenshots. Screener uses a labelled illustration with its app icon; Agora uses abstract artwork.

To preview locally, run `python3 -m http.server 8000` in this directory and open http://localhost:8000.
