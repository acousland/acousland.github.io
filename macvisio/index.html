MacVisio

Familiar diagrams. A native Mac workspace.

MacVisio is a Swift and AppKit diagram editor being developed around Visio document formats. The local prototype supports native editing and a growing set of file features, while full compatibility remains unfinished.

In development. No public download yet.

What you can do

01

Edit with native controls

Create and arrange shapes, connect them, edit text, and work with grouping, undo, pages, layers, and drawing scales.

02

Work with Visio documents

Read and write supported VSDX content, load stencils and templates, and preserve unedited package data. Binary VSD support is experimental.

03

Take the drawing with you

Export drawings as PNG, SVG, or PDF, including multi-page PDF, while compatibility work continues.

Getting started

  1. MacVisio is currently a local development build, with no public installer.
  2. The packaged prototype requires Apple silicon and macOS 27.
  3. Watch this page for a public release as compatibility and distribution work progress.

File compatibility

MacVisio is not yet a complete Visio replacement. Full ShapeSheet behaviour, advanced rendering, specialist solutions, and Office integrations remain unfinished.

Binary VSD output is experimental and has not been validated in Microsoft Visio. Expect compatibility limits with advanced drawings while interoperability testing continues.
