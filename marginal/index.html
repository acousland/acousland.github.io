Marginal

A little room to write.

Marginal is a small native Markdown viewer and editor. Click into the rendered document and write, with ordinary Markdown files underneath and familiar Mac menus and shortcuts around you.

What you can do

01

Edit the page you see

Write directly in rendered text. Use headings, lists, links, quotes, and code blocks, or switch to source when you need it.

02

Tables without the fuss

Insert tables and add, remove, or align rows and columns using native controls. Tab moves between cells.

03

Keep your files simple

Save ordinary UTF-8 Markdown, use native undo and find, and adjust zoom or word wrap to suit your workspace.

Getting started

  1. Download the ZIP, unzip it, and drag Marginal into Applications.
  2. Open a Markdown file or start a new document. Click the rendered text and begin typing.
  3. Save with ⌘S. Use ⇧⌘M to switch between the rendered editor and Markdown source.

Your words remain local

Document contents and file paths stay on your Mac. There is no account or cloud workspace; update checks fetch releases from GitHub.

Advanced or unsupported Markdown can be edited in source view. Remote images display as placeholders while their URLs are preserved.
