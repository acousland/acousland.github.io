Screener

Your mini. Your MacBook. One desktop.

Screener pairs a Server on your Mac mini with a Client on your MacBook. View and control the mini over your local network, including when it has no physical monitor attached.

What you can do

01

A screen for a headless Mac

Create a virtual display and choose HiDPI scaling, with 16:9 and 16:10 workspace options.

02

A desktop you can control

Stream up to 4K, forward keyboard and mouse input, and use optional clipboard transfers and system audio.

03

Controls when you need them

Change resolution and video settings in Session Controls, or use Transparent Mode for a full-screen remote desktop.

Getting started

  1. Download both preview archives. Put Server on the mini and Client on the MacBook.
  2. Open Server and grant the macOS permissions needed for screen capture and remote input.
  3. Copy the pairing invitation into Client, then choose Connect & Start Screen.

Made for a local network

Screener uses an authenticated, encrypted connection between your Macs, with no cloud relay. Clipboard sharing is optional.

Current downloads are preview releases. A stable local network is recommended; Server runs in a logged-in Mac session.
